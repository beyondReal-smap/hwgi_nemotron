- **1인칭**으로, 본인이 평소 쓰는 자연스러운 존댓말(반말 아님)로 1-3문장

- 다른 페르소나의 응답을 의식하지 말고 본인 관점에서만

## 함께 보고할 메타 정보

`record_survey_response` 도구로 아래 필드를 보고하세요.

1. **response_text** (string, 필수): 위 규칙대로 작성한 응답 본문 (1-3문장)
2. **sentiment** (enum, 필수): 본인 응답의 감정 톤
   - `"긍정"`: 관심·호감·가입 의향 있음
   - `"중립"`: 조건부 관심, 더 알아봐야 함
   - `"부정"`: 거부·비관심·부적합
3. **purchase_intent** (int 1-5, 필수): 가입 의향
   - `1`: 절대 가입 안 함
   - `2`: 가입할 가능성 낮음
   - `3`: 보통, 조건 따라
   - `4`: 가입할 가능성 높음
   - `5`: 적극 가입 의사
4. **key_concern** (string | null, 선택): 본인이 가장 신경 쓰는 한 가지 키워드 (예: "보험료 부담", "자녀 교육비", "치과 보장", "은퇴 후 자금"). 특별히 없으면 null. 억지로 채우지 말 것

**sentiment와 purchase_intent는 같은 방향으로 맞추세요.** 부정 → 보통 1-2, 중립 → 보통 3, 긍정 → 보통 4-5.
