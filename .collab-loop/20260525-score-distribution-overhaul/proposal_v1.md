# 점수 산출·대상자 확정 로직 고도화 제안 v1

> 작성: Claude (호스트) / 토론 대상: Codex critique 후 v2 통합

## 1. 문제 정의

대표님 직감: **"점수가 항상 70점대만 나와 신빙성이 안 느껴진다. 분포가 골고루 나와야 할 것 같다."**

이 직감은 데이터로 정확히 뒷받침됩니다.

### 실측 분포 (최근 5개 A/B 분석, 10개 variant, 각 100만 페르소나)

| 지표 | 값 | 의미 |
|---|---|---|
| 전체 평균 점수 | **63~67점** | 100점 척도의 중심이 60점대 |
| 표준편차 | **3.7~4.1점** | 99% 페르소나가 평균 ±10점 안에 |
| 실효 range | **[52, 78]** (26점 폭) | **100점 척도의 26%만 사용** |
| p99 (상위 1%) | **72점** | 백만 명 중 1만 명 컷이 72점 |
| max | **78점** | **80점 이상이 단 한 명도 안 나옴** |

**현재 시스템의 본질적 문제**:
- 100점 만점 척도라고 노출하지만, 실제로는 [52, 78] 사이 26점짜리 척도
- 사용자가 "78점 = 매우 적합"인지 "78점 = 그저 그런 수준"인지 직관적으로 알 수 없음
- 점수 절대값으로 cohort를 정의하려는 시도(예: ≥80 = 핵심 타겟)가 데이터 분포와 어긋남

## 2. 근본 원인 분석

### 점수 산출식 (`apps/api/services/scoring.py:34-37, 314-315`)

```python
W_COSINE = 0.7    # 의미 유사도
W_RULE = 0.2      # 룰 일치 보너스
W_CATEGORY = 0.1  # 카테고리 보너스

cosine_norm = (cosine_all + 1.0) / 2.0   # [-1,1] → [0,1]
combined = 0.7 * cosine_norm + 0.2 * rule_all + 0.1 * cat_all
all_scores = (combined * 100).clip(0, 100)
```

### 각 항의 실제 분포

| 항 | 가중치 | 실제 분포 | 기여도 |
|---|---|---|---|
| `cosine_norm` | 0.7 | 한국어 임베딩 코사인 정규화: 보통 [0.7, 0.95] | 49~67점 |
| `rule_all` | 0.2 | 룰 일치 보너스: 미명시 차원은 만점, 명시 차원은 0/1 → 보통 [0.5, 1.0] | 10~20점 |
| `cat_all` | 0.1 | 카테고리 폴백 0.5 또는 가중치 합 → 보통 [0.5, 1.0] | 5~10점 |
| **합** | 1.0 | | **64~97점이 이론치, 실측은 52~78** |

### 근본 원인 3가지

1. **임베딩 코사인의 좁은 분포**: 한국어 sentence embedding은 동일 도메인 텍스트끼리 코사인이 [0.5, 0.9] 정도로 좁게 분포. 정규화 후 `(x+1)/2`는 [0.75, 0.95]가 되어 모든 페르소나가 60점 이상 보장됨. **0점이 거의 발생하지 않는 구조**.
2. **가산 결합의 평탄화 효과**: 세 항이 모두 양수이고 각자 [0.5, 1] 사이라, 가중 합이 평균 회귀(중심극한정리 비슷한 효과). 분산이 항별 분산보다 작아져 결과 std=4점.
3. **rule_bonus의 페널티 부재**: 타겟 미명시 차원은 모두 만점 부여(`bonus += 0.35` 등). 따라서 모든 페르소나가 거의 만점에 가까운 rule_bonus를 받음.

추가로 `cat_bonus`는 카테고리별 임베딩이 없어 사실상 평탄 폴백(0.5 또는 가중치) → 변별력 거의 없음.

## 3. 개선 방향 — 5개 후보

### 안 A: 모집단 백분위(Percentile Rank) 변환 [추천]

```python
def to_percentile(raw_scores):
    """raw score를 모집단 내 백분위(0~100)로 변환. 균등 분포 보장."""
    ranks = np.argsort(np.argsort(-raw_scores))  # 0이 최상위
    return (1 - ranks / len(raw_scores)) * 100
```

- **장점**: 항상 균등 분포. 0~100 풀 스케일 사용. "85점 = 상위 15%"로 직관 명확.
- **단점**: 안 간 절대 비교가 약해짐 — 모든 안에서 분포가 동일.
- **보완**: raw score 평균/std를 별도 메타로 노출 ("이 안의 절대 매력도"). 또는 percentile만 표시하되 cohort cut은 raw 기준 유지.

### 안 B: Z-score 기반 표준화 (T-score)

```python
def to_tscore(raw_scores):
    """평균 50, std 15가 되도록 표준화 (T-score, 심리측정 표준)."""
    z = (raw_scores - raw_scores.mean()) / max(raw_scores.std(), 1e-6)
    return np.clip(50 + 15 * z, 0, 100)
```

- **장점**: 평균=50, std=15로 정규분포 가정 시 [5, 95]에 99.7% 분포. 직관 명확.
- **단점**: 분포가 정규에 가깝지 않으면 왜곡 가능. raw 분포 모양에 의존.
- **보완**: 시각화에서 분포 모양 함께 표시.

### 안 C: 결합식 재설계 — 곱셈/페널티 강화

```python
# 룰 미일치 시 강한 페널티 (현재 0이 아니라 0.5x 곱셈)
rule_factor = 0.5 + 0.5 * rule_all      # [0.5, 1.0]
cat_factor  = 0.5 + 0.5 * cat_all       # [0.5, 1.0]
combined = cosine_norm * rule_factor * cat_factor   # [0.1875, 1.0]
all_scores = (combined ** 0.5) * 100   # 제곱근으로 분포 펴기
```

- **장점**: 타겟 비일치자가 강하게 떨어짐 → 분포 spread 자연스럽게 확장.
- **단점**: 가산식 직관(가중 평균)이 사라짐. 파라미터 튜닝 필요.

### 안 D: 가산식 유지 + 가중치/스케일 재조정

```python
W_COSINE = 0.5   # 0.7 → 0.5
W_RULE = 0.35    # 0.2 → 0.35
W_CATEGORY = 0.15
# 추가: cosine_norm을 [0.5, 0.95]를 [0, 1]로 재맵핑
cosine_remap = np.clip((cosine_all - 0.0) / 0.8, 0, 1)  # cos 0→0, 0.8↑→1
```

- **장점**: 최소 변경. 가산식 직관 유지.
- **단점**: 분포 spread는 일부만 개선. 70점대 몰림 완전 해소 안 됨.

### 안 E: 하이브리드 — raw score + percentile 이중 노출

- **표시 점수**: 백분위(0~100, 균등 분포) — 사용자 친화적
- **메타 점수**: raw cosine·rule·cat 분해 점수 — 절대 매력도 정보 보존
- **cohort 정의**: raw score 기준 (현재 로직 유지)
- 비교표/카드는 둘 다 노출

## 4. 권장 안 — A + E 하이브리드

**채택 근거:**
1. 대표님 핵심 요구("점수가 골고루 나와야 함")를 직접 해결 (안 A)
2. raw score를 메타로 보존하여 "이 안의 절대 매력도" 정보 유지 (안 E)
3. cohort 분할은 raw 기준을 유지하되, **cohort를 순위 기반으로 재정의**해 직관 명확화

### 구체 변경 계획

#### 변경 1: 점수 산출 후 백분위 변환 추가
- `score_all_personas`에서 `all_scores` 계산 후 `display_scores = to_percentile(all_scores)` 추가
- `all_scores`는 cohort 분할용으로만 사용, 외부에는 `display_scores` 노출

#### 변경 2: cohort 정의를 순위 기반으로 일원화
```python
_COHORT_SPECS = [
    ("core",     "핵심 타겟", 0.5),   # 상위 0.5% (정확히 5,000명)
    ("target",   "타겟층",    5.0),   # 상위 5%   (50,000명)
    ("interest", "관심층",    20.0),  # 상위 20%  (200,000명)
]
# 절대 컷 / max_ratio / 폴백 로직 모두 제거 — 단순화
```

→ **위계 자동 보장**, **A/B 안 모두 같은 인원**(분포 비교는 raw로), **cohort 의미 명확** ("상위 5% = 5만 명")

#### 변경 3: A/B 비교 표에 raw 절대 점수 추가
| 항목 | A안 | B안 | 의미 |
|---|---|---|---|
| 평균 백분위 (표시) | 85 | 92 | 상위 그룹 위치 |
| **평균 raw 점수** | 63.2 | 67.4 | 절대 매력도 (이 안이 얼마나 호응 받는지) |
| **raw std** | 3.8 | 4.1 | 페르소나별 변별력 |

raw 평균 차이(+4.2점)가 A/B의 진짜 매력도 차이 → 비교에 핵심

#### 변경 4: rule_bonus 페널티화 (옵션, 효과 보강)
- 타겟 명시 차원에서 비일치자를 0이 아닌 -0.1 페널티로 (음수 허용)
- 분포 spread 추가 확장

## 5. 검증 계획

1. **백테스트**: 기존 5개 분석의 score_distribution을 백분위 변환해서 정말 균등 분포 나오는지 확인
2. **A/B 차이 보존**: 안 A와 안 B의 차이가 raw 평균 등 메타로 충분히 노출되는지 확인
3. **cohort 의미**: 상위 0.5% = 정확히 5,000명, 위계 자동 보장 확인
4. **사용자 직관**: "85점" 라벨이 "상위 15%"로 즉시 해석 가능한지 카드 라벨에 명시
